ด่านตรวจ rephrase

ไม่ rephrase โหนดอันตรายและโหนดจบเลย ส่วนโหนดอื่น ผลของ LLM ต้องผ่าน checkRephrase ทุกข้อ ไม่อย่างนั้นทิ้งแล้วใช้ต้นฉบับ:

  • ไม่ว่าง ไม่มีลิงก์ ไม่มี markdown หรือ HTML ที่ต้นฉบับไม่มี และไม่แตกหลายย่อหน้า
  • ความยาวอยู่ระหว่าง 0.5 ถึง 1.6 เท่าของต้นฉบับ
  • ชุดตัวเลขต้องเหมือนเดิมทุกตัว โดยแปลงเลขไทยก่อน
  • คำภาษาอังกฤษ เช่น รุ่น รหัส ชื่อปุ่ม ต้องครบและไม่มีคำเกิน
  • จำนวนคำว่า "ไม่" ต้องเท่าเดิม ไม่นับ "หรือไม่" เพื่อกันการกลับความหมาย
ระวังด่านนี้ตรวจรูปผิว ไม่ได้เข้าใจความหมาย ถ้า LLM เปลี่ยนคำกริยาแต่ตัวเลขและคำปฏิเสธเท่าเดิม ก็อาจผ่านได้ จึงปิดเป็นค่าเริ่มต้นและไม่ใช้กับขั้นอันตราย

กันการแต่งข้อมูล (hallucination) หลายชั้น

  1. คำแนะนำไม่ได้สร้างตอนผู้ใช้ถาม จึงไม่มีการแต่งสดบนเส้นทางหลัก
  2. การอ้างอิงมาจากฟิลด์ของผัง (source, page_range) LLM ไม่ได้พิมพ์ตอนรัน
  3. rephrase มีด่านตรวจ และแสดงข้อความต้นฉบับให้กดดูได้
  4. ร่างจาก LLM ต้องผ่าน validator และคนต้องกด publish เอง
ระวัง: อย่าพูดว่า "ระบบไม่มีวัน hallucinate"ความเสี่ยงย้ายไปอยู่ขั้นเตรียมข้อมูล ตอนทำ chunk LLM เคยแต่งคำว่า "blown/tripped" ที่ PDF ไม่มี สคริปต์ตรวจจับได้ แต่ความหมายและคำแปลยังไม่มีคนตรวจ (บท 4)

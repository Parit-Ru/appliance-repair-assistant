# ค้นอาการแบบ "ไม่ทราบรุ่น" (ค้นข้ามรุ่น + คำเตือน)

เปลี่ยนเฉพาะ frontend · backend, traversal engine และ `/symptoms/all` ไม่เปลี่ยน
สถานะ: แก้แล้ว ผ่าน `tsc` + `eslint` · **ยังไม่ได้ดูด้วยตา ยังไม่ได้เรียก backend จริง ยังไม่ commit** · ไม่มีไฟล์เทสต์ใน `frontend/src` (หาไม่เจอ)

## พฤติกรรมใหม่

| ก่อน | หลัง |
|---|---|
| กด "ฉันไม่ทราบรุ่น" → แสดงทุกรุ่นของประเภทนั้น ให้เลือกรุ่นใกล้เคียงเอง | กด "ฉันไม่ทราบรุ่น" → ไป `/symptoms?unknown=1` พิมพ์อาการค้นจากทุกรุ่นได้ทันที |
| คำเตือนอยู่ในกล่องหน้าเลือกรุ่น | คำเตือนอยู่บนหน้าค้น (constant เดียวกับหน้า session) |
| ผลค้นไม่บอกรุ่น (เพราะค้นเฉพาะรุ่นที่เลือก) | ทุกแถวบอกรุ่น · อาการชื่อเดียวกันต่างรุ่น = คนละแถว (หนึ่ง `flowId` ต่อหนึ่งแถว) |
| เริ่ม session ส่ง `manualId` ที่ผู้ใช้เลือก | ส่ง `manualId` ของอาการที่กด + `modelSelection: 'unknown'` ทุกครั้ง |

ระบบ **ไม่เลือกรุ่นให้เงียบ ๆ**: ผู้ใช้เห็นรุ่นของแต่ละแถวและเลือกเอง · ถูกบันทึกเป็น `unknown` · หน้า session แสดงกล่องเตือน · ด่าน `safety_critical` ใน traversal engine ไม่ถูกแตะ (ยังต้องอ่านและกดยืนยันเหมือนเดิม)

## ไฟล์ที่แก้ (8 ไฟล์ ทั้งหมดใน `frontend/src`)

| # | ไฟล์ | แก้อะไร |
|---|---|---|
| 1 | `lib/modelSelection.ts` | เพิ่ม `UNKNOWN_MODEL_NOTICE_TITLE`, `UNKNOWN_MODEL_SEARCH_PATH` · `otherSymptomsPath`: `'unknown'` → กลับไปค้นข้ามรุ่น (ไฟล์ 7) |
| 2 | `pages/SessionPage.tsx` | ใช้ constant แทนข้อความตรง ๆ (ข้อความเหมือนเดิม) |
| 3 | `components/SymptomRow.tsx` | prop เสริม `modelLabel` แสดง "รุ่น: …" |
| 4 | `components/SymptomSearchResults.tsx` | prop เสริม `modelLabelFor` ส่งต่อให้แถว |
| 5 | `pages/SymptomsPage.tsx` | รับ `unknown=1` ไม่มี `manual` · ค้นข้ามรุ่น · จับคู่ `flowId` กับรุ่นผ่าน `useFlows()` · ซ่อนลิงก์ "ดูอาการทั้งหมด" ในโหมดนี้ |
| 6 | `pages/DevicesPage.tsx` | ปุ่ม "ฉันไม่ทราบรุ่น" พาไปหน้าค้น · ลบ state/กล่องเตือนเดิม |
| 8 | `pages/HistoryDetailPage.tsx` | ป้าย "ของรุ่นนี้" เฉพาะ `modelSelection === 'selected'` |

## ทำไมจับคู่ `flowId` ฝั่ง frontend

ผลค้นของ backend ไม่มี `manualId`/ยี่ห้อ/รุ่น และห้ามแตะ backend จึงใช้รายการผังทุกรุ่นที่ `useFlows()` ดึงอยู่แล้ว (แคชร่วมกับหน้า session)

## ข้อจำกัดที่ยังมี

1. backend คืนผลค้นสูงสุด 3 รายการ (`MAX_RESULTS = 3`) · ค้นข้ามรุ่นแล้วอาการคล้ายกันหลายรุ่นอาจกินที่ทั้ง 3 ช่อง
2. ปุ่ม "ฉันไม่ทราบรุ่น" ทิ้งบริบทประเภทเครื่อง (ค้นทุกประเภท)
3. กล่องเตือนใช้ข้อความ "คุณเลือกรุ่นที่ใกล้เคียง ขั้นตอนอาจไม่ตรงกับเครื่อง" ซึ่งเขียนไว้สำหรับหน้า session · บนหน้าค้นผู้ใช้ยังไม่ได้เลือกอะไร (ถ้อยคำเป็นของผู้พัฒนา ยังไม่ได้แก้)
4. ข้อความวิธีหาเลขรุ่นเหลือแค่ `MODEL_MATCH_HINT` (เดิมละเอียดกว่า: ขอบประตู/ด้านหลัง/ปกคู่มือ)
5. ข้อความที่ผมเพิ่มเอง (ไม่ใช่ข้อความความปลอดภัย): "ไม่ทราบรุ่น: ค้นจากทุกรุ่น · เลือกรุ่น", "กำลังโหลดรายการรุ่น", "รุ่น:", และท้ายกล่อง "ไม่พบรุ่นที่ตรงกับที่พิมพ์" → "…เพื่อค้นอาการจากทุกรุ่น"
6. ลิงก์เก่า `?manual=…&unknown=1` ยังเข้าได้ (พฤติกรรมเก่า) แต่ไม่มีปุ่มไหนสร้างลิงก์นี้แล้ว
7. คอมเมนต์ที่ `HistoryDetailPage.tsx:82–83` ยังอธิบายเฉพาะกรณี `null` (ไม่ได้แก้ เพราะอนุมัติแค่บรรทัดเดียว)

## ที่ต้องดูด้วยตา

1. `/devices` → เลือกประเภท → "ฉันไม่ทราบรุ่น" → เห็นกล่องเตือน ไม่ redirect
2. ค้นอาการ → ทุกแถวมี "รุ่น: …" · อาการเดียวกันต่างรุ่นแยกแถว
3. กดอาการ → หน้า session มีกล่องเตือน · ขั้นตอนที่มี safety ต้องกดยืนยัน
4. ประวัติของ session นี้ → ปุ่มเขียน "ตรวจอาการอื่น" (ไม่มี "ของรุ่นนี้") และพาไปค้นข้ามรุ่น
5. รีเฟรชหน้า session / เปิดแท็บใหม่ → กล่องเตือนยังอยู่ (อ่านจาก `session.modelSelection` ที่ server)

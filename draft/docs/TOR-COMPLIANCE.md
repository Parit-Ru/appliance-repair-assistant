# ตารางเทียบ TOR กับระบบ (Traceability Matrix)

เทียบ TOR "ระบบช่วยเหลือและแนะนำการซ่อมเครื่องใช้ไฟฟ้าภายในบ้าน" (ปริตต์ รุ่งเรือง / อ.ดร.ศศิน เทียนดี) ทีละข้อกับระบบ ณ **14 ต.ค. 2569** (ปรับจากฉบับ 13 ต.ค. ดู §0)

| สัญลักษณ์ | ความหมาย |
|---|---|
| ✅ | ทำแล้วและมีหลักฐานที่รันซ้ำได้ |
| 🔶 | ทำบางส่วน หรือทำแล้วแต่ติดเงื่อนไข |
| ❌ | ยังไม่ได้ทำ |
| ❓ | ยังไม่ได้ตรวจ/ไม่มีข้อมูล |

ระบบที่ deploy: backend `https://appliance-repair-assistant.onrender.com` · frontend `https://parit-ru.github.io/appliance-repair-assistant/`

## 3. วัตถุประสงค์ (§2) และผลที่คาดว่าจะได้ (§5)

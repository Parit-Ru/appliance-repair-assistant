# แผนงานที่เหลือทั้งหมด (13 ต.ค. 2569 → ปลายเดือน ต.ค.)

เป้าหมาย: ให้ระบบ เอกสาร และหลักฐาน ตรงกับ TOR ให้มากที่สุดภายในเวลาที่เหลือ โดย **ไม่แต่งข้อมูล ไม่อ้างผลที่ยังไม่มี**

> เวลาที่เหลือตาม TOR: ประมาณ 2–3 สัปดาห์ (วันสอบ/กำหนดส่งจริงยังไม่ทราบ — ใส่ใน `ADVISOR-QUESTIONS.md` Q6) · ตัวเลขเวลาในตารางเป็น **ค่าประมาณของผม ยังไม่ได้วัดจากความเร็วของคุณ** ปรับเมื่อมีข้อมูลจริง

## 1. สถานะ ณ ตอนนี้

| ด้าน | สถานะ |

## 4. ความเสี่ยง

| ความเสี่ยง | ผลกระทบ | ลดความเสี่ยง |
|---|---|---|
| หาเพื่อนไม่ได้ 15–20 คน / ได้ไม่ถึง 40 ข้อ | ชุดรายงานเล็ก ผู้เขียนน้อย ช่วงความเชื่อมั่นกว้าง | ใช้ฟอร์ม (3 คน ≈ 50 ข้อ); ถ้าไม่ถึง ใช้แผนสำรอง §5.1 และรายงานเป็น "ผลบนชุดพัฒนา" พร้อมระบุจำนวนผู้เขียน |
| แรม Render free ไม่พอเมื่อเปิดโมเดล | ค้นหาล้ม/แอปรีสตาร์ท | B3: ปิดกลับ + ทดสอบเต็มรูปแบบในเครื่องสำหรับวันสาธิต |
| ข้อมูลประเภทใหม่ผิดในเรื่องความปลอดภัย | อันตรายต่อผู้ใช้ + เสียน่าเชื่อถือ | ตรวจโดยบุคคลที่สอง; ไม่เร่ง; จำนวนผังน้อยแต่ถูกดีกว่า |
| เปลี่ยนระบบหลังล็อกชุดรายงาน | ตัวเลขรายงานใช้ไม่ได้ | ล็อกโค้ดหลังรัน D4; ทำ C ก่อน D4 |
| Render หลับ/ล่มวันสาธิต | สาธิตไม่ได้ | ปลุกก่อน 2 นาที + รันในเครื่องเป็นแผนสำรอง |
| Groq ล่ม/ช้า/ชื่อโมเดลเปลี่ยนวันสาธิต | ขั้นตอนช้า | มี fallback + วงจรตัดแล้ว (ใช้ข้อความต้นฉบับทันที); ปิดฟีเจอร์ได้ด้วยการเอา `REPHRASE_ENABLED` ออก ไม่ต้อง deploy |
| ฐานข้อมูลใช้ร่วมกับ FixStep | ข้อมูล session ปนกัน / migration กระทบกัน | ไม่รัน `migrate`/`seed` ใหม่โดยไม่จำเป็น; F6 |

## 5. สิ่งที่ผมจงใจ "ไม่ทำ" และเหตุผล

| เรื่อง | เหตุผล |
|---|---|
| เขียนผังของไมโครเวฟ/ตู้เย็น/ทีวี/เครื่องซักผ้าเอง | เนื้อหาซ่อมที่เกี่ยวกับไฟฟ้า/ความร้อนต้องมาจากคู่มือและตรวจโดยคน การแต่งจากความรู้ทั่วไปขัดหลักการของ TOR และอาจอันตราย — ให้แม่แบบ ตัวตรวจ และคู่มือขั้นตอนแทน |
| แก้โค้ดจริงใน `backend/`/`frontend/` | ตามที่สั่ง: ใส่ใน `draft/` — การนำเข้าเป็นการตัดสินใจของคุณ (patch ตรวจแล้วว่าใช้ได้) |
| เติมคำค้นลงชุดรายงานผล | ผิดกติกา: ผู้ช่วย AI ต้องไม่เห็น/ไม่ติด label ชุดรายงานผล |
| เขียนการอ้างอิงวรรณกรรม | ไม่ต้องการแต่งเอกสารอ้างอิง |
| เปิดใช้ RAG/หน้า `/ask` | เลื่อนไว้ตามขอบเขต และมีช่องโหว่ F.12 ที่ต้องออกแบบก่อน |
